> 📝 **Weekly Review — The most important hour of your week.** Block 60–90 min. Do it Sunday evening or Monday morning. This is the system that makes everything else work.

---

## ⏱️ Before You Begin

- [ ] Find a quiet spot, no distractions
- [ ] Open `daily-brief` to see where you stand
- [ ] Have Toggl open — make sure last week is finalized
- [ ] Grab water or coffee
---

## Phase 1: Get Clear — Process Everything

- [ ] Collect all loose papers, voice memos, receipts
- [ ] Process physical inbox to zero
- [ ] Process email to zero (archive, delete, or add to Inbox)
- [ ] Process LifeOS Inbox to zero:
  [→ Open Inbox](https://www.notion.so/f1f0808804614362affa54ca7b96fe8a)

  For each item: Do it (< 2 min), Delete it, Delegate it, or Create a Task

- [ ] Clear phone notes app to Inbox
- [ ] Check texts — any outstanding replies?

## Phase 2: Get Current — Review Everything

### ✅ Next Actions (Tasks)

[→ Open Master Tasks](https://www.notion.so/90d0ac2c729345a2a3ebc32431713193)

- [ ] Review all "Today" and "Next" tasks
- [ ] Mark any completed tasks as done
- [ ] Add new tasks that emerged this week
- [ ] Are any tasks stuck? Reschedule or delete.
### 📁 Projects

[→ Open Projects](https://www.notion.so/39efe494e52a4e5e97f26c8752fcf4e8)

- [ ] Does each active project have a clear Next Action?
- [ ] Update Progress % on each project
- [ ] Any projects stalled? Decide: push, defer, or kill.
- [ ] Any projects to promote from Someday → Active?
### 🎯 Goals

[→ Open Goals](https://www.notion.so/486b9c5ea11d480caa2e0bf9e963c3b2)

- [ ] Are goals on track? Update progress.
- [ ] Which goal needs the most attention next week?
### 👥 Relationships (CRM)

[→ Open Contact CRM](https://www.notion.so/dc9a092b12f0438c93ed3eecf0eb0297)

- [ ] Who's overdue? Send a message, make a call.
- [ ] Update Last Contact dates for anyone you connected with.
### 💰 Finances

[→ Open Finance Dashboard](https://www.notion.so/30dc051d73d2816586b7c0e7a59fdfb8)

- [ ] Log any untracked transactions
- [ ] Check budget status — any danger zones?
- [ ] Any bills due next week?
### 🔄 Habits

[→ Open Habits](https://www.notion.so/f39b076620164b6cb221b58540bbc23c)
